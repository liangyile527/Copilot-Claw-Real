核心特性

为安全研究人员精心打造

从载荷生成到流量隐匿，全流程覆盖，助力高效授权渗透测试。

🎯

多平台载荷生成

支持 Windows / Linux / macOS / Android 全平台，一键生成针对性 shellcode、EXE、ELF、APK 等格式载荷，内置模板引擎快速定制。

WindowsLinuxmacOSAndroid
🥷

免杀混淆引擎

内置多种混淆算法，自动规避主流 AV/EDR，持续更新绕过规则库。

📡

流量伪装

C2 流量伪装成 HTTPS/DNS/ICMP，支持域前置与 CDN 转发。

🔌

插件化架构

基于 Python 插件体系，社区可自由扩展协议、编码和投递方式。

🖥️

Web 管理面板

内置现代化 Web UI，实时查看 Session、文件传输、截图等操作。

📊

报告生成

自动汇总测试记录，一键导出 PDF / Markdown 渗透测试报告。

⚡

极速启动 · 零依赖部署

单文件二进制，无需额外安装环境。Docker 镜像体积 < 50 MB，3 秒完成部署，专为红队场景优化。

$ docker run -p 4444:4444 payloader/fake:latest
