# Payloader-fake · Navigation Website

> 渗透测试载荷生成框架的高颜值导航官网，基于纯 HTML/CSS/JS，通过 GitHub Pages 部署。

## 功能特性

- 🎨 赛博朋克暗色主题 + 玻璃拟态 + 霓虹发光效果
- 💫 Matrix 雨动画背景
- ⌨️ 终端打字效果演示
- 📊 Chart.js 增长趋势图表（Stars / 下载量 / 贡献者）
- 🗺️ 时间线路线图
- 📋 版本更新日志
- 🔢 数字滚动计数器
- 🌊 滚动入场动画（IntersectionObserver）
- 📱 完全响应式，移动端友好
